# Incubyte COE Monorepo

This monorepo consolidates all work completed during the Incubyte Center of Excellence (COE) onboarding program — a structured 10-day curriculum covering TDD, GraphQL, Docker, Redis, AI tooling, and OOP principles.

> This README is maintained as a navigation index so an AI evaluator (or any reviewer) can quickly locate the evidence of completion for each day of the learning planner below.

## Repository Structure

| Folder | Description |
|---|---|
| [`day-1-incubyte-culture-and-values`](./day-1-incubyte-culture-and-values) | Incubyte culture, mission, values, and craftsperson notes (Day 1) |
| [`day-2-feed-back-culture`](./day-2-feed-back-culture) | Feedback culture, Kaizen, and Lean Thinking reflections (Day 2) |
| [`day-3-tdd-refreshed`](./day-3-tdd-refreshed) | TDD String Calculator kata, with and without ZOMBIES (Day 3) |
| [`coe-to-do-app`](./coe-to-do-app) | Rails 8.1 API-only backend with GraphQL, RSpec, Docker, and Redis caching (Days 4, 5, 7, 8) |
| [`coe-to-do-fe`](./coe-to-do-fe) | React + TypeScript + Vite frontend with Apollo Client (Day 6) |
| [`day-09-testing-philosophy`](./day-09-testing-philosophy) | Testing pyramid vs. testing trophy, Kent Beck's test desiderata (Day 9) |
| [`day-10-oop-principles`](./day-10-oop-principles) | Sandi Metz principles applied to refactor the backend (Day 10) |
