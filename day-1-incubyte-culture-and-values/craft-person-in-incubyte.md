 ### What it means to be a craftsperson at Incubyte
 
 Being a Software Craftsperson at Incubyte means prioritizing how code is built just as much as what is being built, treating software development as an intentional, high-quality art form rather than a transactional assembly line.

 It follows the below Engineering Principles

 - Extreme Programming (XP):
 - TDD
 - Clean code and refactoring
 - Pragmatic Quality
    - Demanding technical excellence and clean architectures while maintaining a sharp focus on practical, real-world delivery.
 - Extreme Ownership
